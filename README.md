# 🎓 Face Recognition Attendance System

A real-time Face Recognition Attendance System built using **Python, Flask, OpenCV, and face_recognition**.  
This system automatically detects faces using a webcam and marks attendance in a database.

---

## 🚀 Features

✅ Student Registration with Face Encoding  
✅ Real-time Face Recognition via Webcam  
✅ Automatic Attendance Marking  
✅ Live Camera Feed with Detection  
✅ Attendance Dashboard  
✅ Confidence Score Display  
✅ SQLite Database Storage  
✅ Modern Dark UI using Bootstrap  

---

## 📸 How it Works

1. Register student face  
2. Face encoding is saved  
3. Webcam detects face  
4. System matches encoding  
5. Attendance marked automatically
